```text
design → (impl-backend ‖ impl-frontend) → review → integration
```

  （内容确定性：同候选集重建同哈希、回归记录不入哈希、completed 后哈希不变——三条断言均过）。

  review 报告 `fa0282d5217fd00b…`；集成后 check_freshness 对批准 sha 返回空（无失效）。
- 版本级回归：真实子进程在集成目录运行契约入口冒烟（import app.api → add_task →

## 真实路径 vs 模拟点（逐条）

真实（非 mock，全部 kernel 模块实跑）：

1. 调度：`build_graph`/`ready_set`/`order_ready` 真实建图与就绪集驱动派发顺序。
2. 隔离：`prepare_dispatch` = OwnershipRegistry claim（backend `app/…` 与 frontend
   `web/…` 不相交）+ WorkspaceManager 真实 `git worktree add`；`changes` 恰报
   `app/` 与 `web/` 各一目录新增；cleanup 后在册清空且 worktree prune。
3. 租约：LeaseManager 真实文件锁——领取 epoch=1、第二 worker 领取被拒（"租约未过期"）、
   续约、释放后 state 为 None。
4. 审查：ReviewBoard 真实流转——实现者身份落审查结论被拒（"自审"）；独立审查员
   （companion-checker）批准后 impl 才能 done；review 任务同样过 done 门且由集成者
   身份（companion-integrator）独立批准。
5. 集成：IntegrationBoard 候选门（无有效批准 / sha 不一致即拒绝）、版本幂等、两级回归门、
   complete 门全部真实执行。
6. 回归与操作验证：三个真实 Python 子进程（版本级冒烟、全新一次 API 调用、HTTP 服务器）
   在真实集成目录运行，数据真实落盘 JSON。

模拟（如实声明，不虚报）：

1. **开发者产出以"测试内文件写入"模拟**：把示例代码写入各自隔离工作区，代替真实
   F2/B2 模型生成代码——代码内容本身已作为示例交付（可运行、经真实操作验证）。
2. **审查者以不同 attempt 身份角色扮演**：无真实多模型并发派发；独立性由 ReviewBoard
   的身份校验真实拒绝自审来保证，但"模型独立判断"未验证。
3. **并行是"并行就绪 + 各自隔离工作区"的串行派发**：调度器本就不承诺并行执行；
   真实多模型并发派发属宿主 DWF 的持续验证主题，本记录不 claim。
4. human_trial（真实用户浏览器走查）NOT_RUN；api_contract 的幂等键为如实声明的
   未实现限制（重复 add 会产生重复任务），并发写竞争未实测（契约 measurement_required 已注明）。
