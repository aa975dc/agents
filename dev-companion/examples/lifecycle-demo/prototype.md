# 本地支出合计原型

这是自动化生命周期演示的静态页面草图，未声称用户已经试用。

```text
DEV COMPANION · 本地演示
这次一共花了多少？
支出金额 [20,30                        ]
提示：逗号分隔，金额大于或等于 0
[             计算合计               ]
合计：50
```

主路径：打开页面 → 输入 20,30 → 点击计算 → POST /api/sum → 显示合计 50。
状态：等待计算、正在计算（按钮禁用）、计算成功、无效输入提示、请求失败提示。
失败示例：输入 -1,20，后端返回 422，页面解释金额不得为负数；用户可修改后重试。
数据变化：仅请求中传递金额，服务不保存记录。页面关闭无需取消持久化任务。
验收区分：自动检查覆盖 Python、HTTP 和 HTML 内容；浏览器交互与真实用户反馈由独立步骤完成。
