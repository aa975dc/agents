description: 独立检查成果并引导试用，满足条件后记录验收
argument-hint: "[功能编号或试用反馈]"
skills: dev-companion
---

按技能与 CLI 约定读取当前状态。输入 `$ARGUMENTS` 可指定功能或提供真实反馈。存在多个候选而无法识别时，请用户选要检查的功能。

主会话将当前需求、项目路径、功能编号和产物位置交给新的 `companion-checker` Agent。检查者自己读取产物并运行 `check --feature ID`。无需重复同一内容的刚完成独立检查，但必须确认内容未变且记录仍新鲜。

自动检查通过后核对验收例子覆盖情况。检查失败或未执行时如实保留缺口，不验收。没有可执行检查时说明首版限制，补充有意义的检查需要更新并确认范围，不使用无实际断言的占位命令。

若该功能要求用户试用，提供“在哪里打开 → 做什么 → 应看到什么”的具体步骤，等用户实际反馈。用户说符合本次要求且当前检查仍有效时，才执行 `accept --feature ID --note "实际验收说明" --user-confirmed`。不需要主观验收的已确认功能可以在条件满足后执行不带确认参数的 `accept`。

最后读取 `status`。100% 表示本版范围已验收，分别说明是否已存档及是否已经发布。
