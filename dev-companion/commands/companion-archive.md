读取本插件技能和 `references/cli-contract.md` 的本地快照约定。用户输入：`$ARGUMENTS`。先确定是查看、保存还是恢复；未说明操作时展示历史与可选操作，不默认恢复。

- **查看**：运行 `history`，显示摘要、时间和实际保存范围。
- **保存**：读取并列出本次显式选择的普通文件，调用 `save --paths ... --summary ...`。保存成功才报告快照编号；不要把目录、敏感文件或软链接加入，不承诺全盘备份。
- **预览恢复**：取得用户指定的真实快照 ID，先确认开发者及其它写入者已停止，再调用 `preview-restore --archive ID`。展示即将替换、新增、删除的纳管文件、未覆盖内容和保护方式。
- **确认恢复**：只有用户已确认这一次具体预览，才用原预览返回的 ID 与令牌调用 `restore --archive ID --token TOKEN`。没有同一预览确认或内容已变时重新预览，不能自行补确认。实际仍在运行的任务需先停止，再如实记录中止原因，不能只改成受阻就假装进程停了。
- **撤回恢复**：读取上次恢复实际生成的保护快照 ID，针对它重新预览、确认、恢复。不猜保护编号，不使用 `git revert` 代替内容恢复。

恢复后核对结果和保护快照是否实际成功，再读取进度，提示受影响功能重新检查。错误时报告真实已完成/未完成部分，保留证据，不宣称已恢复。

清楚说明：只恢复预览列出的纳管文件；后来显式纳管而目标快照没有的文件可能被删除；未纳管文件、Git 历史、数据库和线上服务不包含在内。
